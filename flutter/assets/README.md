# Assets

Ce dossier contient les assets de l'application StudyNest.

## Logo

Ajoutez votre fichier `logo.png` dans ce dossier. Le logo doit être:
- Format PNG
- Taille recommandée: 512x512 pixels
- Fond transparent (de préférence)
- Nom exact: `logo.png`

Pour l'instant, vous pouvez utiliser un placeholder temporaire ou créer un simple logo avec les initiales "SN" (StudyNest).
