# Politique de confidentialité — StudyNest

Dernière mise à jour : 1 octobre 2026

StudyNest est une application mobile dédiée à l'organisation des études, des matières, des notes, des documents et des tâches. Cette politique explique quelles données sont traitées, comment elles sont utilisées et quels droits tu as sur elles.

## 1. Rôle de l'application

StudyNest peut stocker et organiser :
- les matières suivies ;
- les notes et fiches de révision ;
- les documents enregistrés ;
- les tâches à faire ;
- les préférences visuelles et thématiques ;
- le profil utilisateur lorsque l'authentification Firebase est activée.

## 2. Données collectées

### 2.1 Données stockées localement

Dans sa version actuelle, l'application stocke une grande partie des informations sur l'appareil de l'utilisateur, notamment :
- matières ;
- documents ;
- notes ;
- priorités et rappels ;
- préférences de thème ;
- configuration locale de l'application.

Ces données sont conservées localement pour permettre un usage hors ligne et une meilleure expérience d'étudiant.

### 2.2 Données si des services Firebase sont activés

Si tu active des fonctionnalités cloud ou d'authentification Firebase, l'application peut traiter des données supplémentaires telles que :
- adresse e-mail liée au compte utilisateur ;
- identifiant Firebase ;
- données de profil utilisateur ;
- documents ou éléments synchronisés depuis le cloud.

Ce type de traitement est limité aux fonctionnalités réellement activées sur le compte et ne sert pas à la publicité.

## 3. Utilisation des données

Les données sont utilisées pour :
- organiser les études ;
- retrouver les matières et documents rapidement ;
- sauvegarder les notes et tâches ;
- personnaliser l'expérience visuelle ;
- activer les fonctionnalités de synchronisation si elles sont disponibles.

StudyNest ne vend pas les données des utilisateurs et ne les utilise pas pour cibler de la publicité.

## 4. Partage des données

StudyNest ne partage pas les données personnelles avec des annonceurs ni des tiers commerciaux.

Seuls des fournisseurs techniques nécessaires au fonctionnement de l'application peuvent traiter des données, notamment :
- Firebase Authentication ;
- Firebase Firestore ;
- Firebase Storage ;
- Google Sign-In lorsque cette fonctionnalité est activée.

## 5. Sécurité

Nous mettons en place des mesures raisonnables pour protéger les données utilisateur contre l'accès non autorisé, la perte ou l'altération. Cependant, aucun système n'est totalement infallible, et il convient d'utiliser des mots de passe forts et de maintenir l'application à jour.

## 6. Stockage local et suppression

Les données stockées localement restent sur l'appareil tant que l'application est installée. L'utilisateur peut les supprimer :
- en désinstallant l'application ;
- en vidant le stockage de l'application depuis les paramètres Android ;
- en supprimant son compte ou ses données si un service cloud est activé.

## 7. Droits de l'utilisateur

L'utilisateur peut demander :
- l'accès à ses données ;
- la correction de données inexactes ;
- la suppression de ses données ;
- la limitation de l'utilisation de ses données lorsque le traitement le permet.

Pour toute demande, l'utilisateur peut nous contacter via l'adresse e-mail indiquée ci-dessous.

## 8. Enfants

StudyNest n'est pas spécialement conçu pour des enfants de moins de 13 ans. L'application ne collecte pas sciemment de données personnelles d'enfants à des fins marketing ou publicitaires.

## 9. Modifications de la politique

Cette politique peut être mise à jour afin de refléter les évolutions de l'application, des services utilisés ou des exigences légales. Les changements importants seront signalés dans les mises à jour de l'application.
